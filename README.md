# I AM SENSING A CONNECTION — Dating App Playback V8

React + Vite + Three.js phone playback interface.

## Run locally

```bash
npm install
npm run dev
```

Open the URL printed by Vite.

## Map update

Explore now generates city blocks well outside the visible map bounds, eliminating empty margins on narrow or tall screens. Default orientation puts Nellie above and YOU below; the gold route connects them. Buildings on the outer perimeter use simplified geometry for mobile performance.

## Assets

- Nellie images: `public/photos/1.jpg` through `5.jpg`
- To use your licensed custom font, copy `ZEN-SERIF-REGULAR.OTF` into `public/fonts/` (not included in ZIP).

## GitHub Pages

Repo: `JiazhenLuo/I-AM-SENSING-A-CONNECTION-DATING-APP`. The Vite production base is configured for this exact repo.

GitHub: Settings → Pages → Build and deployment → Source: **GitHub Actions**. Push to `main` to deploy.

After installation, open HTTPS site in iPhone Safari → Share → Add to Home Screen → Open as Web App to remove Safari toolbars.
